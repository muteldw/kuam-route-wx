# kuam-route-wx

K-UAM 경로 기상 위험 단순 진단모델과 웹 표출 초안 (킨텍스 V5 → 여의도).

> 현재는 **합성 시나리오 자료**로 동작하는 시연판입니다. 위치·수치는 설명용이며 운항 판단에 쓰면 안 됩니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `model/kuam_simple_model.py` | 진단모델 참조 구현(파이썬, 외부 패키지 없음). 경로 판정 결과를 JSON으로 출력 |
| `web/index.html` | 단일 파일 웹 대시보드. 같은 모델을 JavaScript로 내장해 브라우저에서 바로 계산 |

## 실행

```bash
# 경로 판정 요약
python model/kuam_simple_model.py --scenario conv --aircraft lift --lead 0.5 --summary
# 전체 결과(JSON)
python model/kuam_simple_model.py --scenario llj --aircraft tilt --lead 0 > route.json
# 웹: web/index.html 을 브라우저로 열기
```

시나리오: `calm`(가을 약풍), `nw`(겨울 북서풍), `llj`(야간 저층제트), `conv`(대류성 돌풍전선), `fog`(새벽 한강 안개)
기체(가상): `multi`(멀티콥터형), `lift`(리프트+크루즈형), `tilt`(틸트로터형)

## 모델 요약

- 평균풍: 600 m 일반풍 기준 멱법칙, α = f(z₀, 안정도). z₀: 한강 0.0002 m, 도시 0.5 m, 농경지 0.1 m, 공항 0.03 m
- 킨텍스 V5 국지 증폭: MUKLIMO_3 민감도 결과(평균 약 1.58배, 북풍 최강·남풍 최약) 근사
- 야간 저층제트, 지표 풍향 반전(순전), 여의도 건물 후류
- 난류: `ε = u*³/(κ·max(z,50))` + 대류항 + 제트 시어항, `EDR = ε^(1/3)`
- 급변풍: 비행경로상 `F = (dWx/dt)/g − w/V` (1 km 이동평균, 주의 0.07 / 경고 0.105)
- 대류셀: 이동 하강기류 + 방사형 유출풍 + 강수
- 안개·운고·착빙: 습도·약풍·야간 조건, 이슬점차 기반
- 판정: 항목별 여유율 `1 − 예측값/기체 한계`의 최솟값 → 정상(≥20%) / 주의 / 경고(≥−25%) / 불가

## 실측 연결 계획 (다음 단계)

| 현재 항목 | 교체할 자료 |
| --- | --- |
| 600 m 일반풍, 기온, 이슬점 | 기상청 API허브 LDAPS·KIM + ECMWF IFS/AIFS 블렌딩 |
| 버티포트 증폭 근사식 | MUKLIMO_3 40케이스 조견표 → 3D U-Net 다운스케일 |
| 대류셀 시나리오 | 레이더 합성장 외삽(pySTEPS) |
| 안개 시나리오 | AWS 시정계·GK2A 안개탐지 |
| 급변풍 탐지 | 버티포트 도플러 라이다 실시간 스캔 |

# kuam-route-wx

**버전 1.2.1** (2026-11-17) · 작성자 이동원 (Dong-Won Yi) · yidongwonyi@gmail.com · 변경 이력은 [CHANGELOG.md](CHANGELOG.md)

K-UAM 경로 기상 위험 · eVTOL 배터리 · 항로 추천 단순 진단모델과 웹 콘솔 (수도권 서북부: 킨텍스 V5 ~ 여의도·용산).

> 현재는 **합성 시나리오 자료**로 동작하는 시연판입니다. 버티포트 위치·수치는 설명용이며 운항 판단에 쓰면 안 됩니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `web/index.html` | 단일 파일 웹 콘솔. 모델을 JavaScript로 내장해 브라우저에서 바로 계산 |
| `model/kuam_simple_model.py` | 같은 모델의 파이썬 참조 구현(외부 패키지 없음). 항로 3개 추천·배터리 계산 CLI |
| `data/fleet.json` | 국가별 eVTOL 10종 제원(출처·기준일)과 모델용 추정 파라미터 |
| `web/basemap.json` | 기본도 자료(한강, 시군구·읍면동 경계, 주요도로) |
| `tools/build_basemap.py` | 기본도 생성 스크립트 (Natural Earth 10m, 통계청 2018 경계) |

## 웹 콘솔 기능

- **경로 설정**: 예시 버티포트 목록, ‘지도에서’ 클릭, 출발·도착 핀 끌기, 지도 오른쪽 클릭
- **항로 3개 추천**: 최단 시간 · 최소 위험 · 한강 회랑. 위험도 지수 가중 격자 탐색(다익스트라) + 직선화, 순항고도 후보(상한, −150, −300 m) 중 선택. 김포공항 반경 2.6 km 회피
- **고도별 기상**: 바람, 돌풍, 난류(EDR), 급변풍(F-factor·수평·연직), 기온(감률·야간 역전), 습도, 운량·운고, 비·눈(기온으로 구분), 뇌우, 착빙, 시정
- **위험도 지수(0~100)**: 기체 운용 한계 대비 여유율의 최솟값. 지도 수평분포, 항로 색, 단면, 경로 기상 그래프에 표시
- **지도 시간**: 수평 지도는 출발 시각부터 1·3·6·24시간을 스스로 반복 재생하고, 비행 재생이 시작되면 기체 시각(출발 + 경과)에 맞춰 함께 흐름. 확대·축소 후 ‘원래 크기’ 버튼
- **비행 재생**: 수직 이륙 → 상승 → 정속 순항 → 하강 → 수직 착륙. 연직 단면과 지도에서 UAM 아이콘이 움직이고 고도·속도·바람·기온·전력·위험도를 실시간 표시. 배속 1~300배
- **불가 조건 사고 재현**: 위험도 80 이상 구간·배터리 소진·중량 초과가 있으면 재생 전에 이륙 불가 경고. ‘그래도 비행’을 고르면 해당 지점에서 추락 애니메이션과 함께 재생을 멈추고 사고 보고(시각·위치·고도·원인·한계값)와 안전한 추천 항로 전환을 제시
- **속도 슬라이더**: 이륙 구간·정속 순항·착륙 구간 속도, 순항고도 상한, 상승·하강률. 대지속도 = 대기속도 + 경로방향 바람
- **기체 선택**: 미국(Joby, Archer, Wisk), 중국(EHang, AutoFlight), 독일(VoloCity), 영국(Valo), 브라질(Eve), 일본(SkyDrive), 한국(Supernal)
- **탑승 인원**: 조종사·성인·어린이, 수하물. 좌석·최대 탑재량·최대이륙중량 점검
- **배터리 소비**: 단계별 전력(kW)·소비량(kWh), 많이/적게 쓰는 구간, 도착 잔량
- **기체별 운항 민감도**: 같은 조건에서 10종 비교, 상층풍 세기별 위험도·배터리 사용률
- **누적 통계·학습**: 비행 기록을 페이지 데이터베이스에 저장, 실측 소비량 입력 시 기체별 보정계수 k = Σ(실측×예측)/Σ(예측²) 학습, 맞바람에 따른 kWh/km 증가율 회귀

## 파이썬 실행

```bash
python model/kuam_simple_model.py --list-aircraft
python model/kuam_simple_model.py --from "킨텍스 V5" --to 여의도 --aircraft joby --adult 2 --child 1 --scenario conv
python model/kuam_simple_model.py --from 마곡 --to "상암 DMC" --aircraft ehang --adult 1 --scenario snow --json > plan.json
```

시나리오: `calm` 가을 약풍, `nw` 겨울 북서풍, `llj` 야간 저층제트, `conv` 여름 뇌우·돌풍전선, `rain` 장마 비, `snow` 겨울 눈, `fog` 새벽 한강 안개

## 기체 자료 주의

- 공개 제원은 각 기체의 출처(eVTOL News/VFS, 제조사 발표 등)에서 2026-11-17에 확인했습니다. 출처마다 기준일이 다릅니다.
- 미공개 값(일부 MTOW·탑재량·순항속도·항속)은 `*Est: true`로 표시한 추정값입니다.
- 배터리 용량은 공개 항속거리를 최대이륙중량·예비 20%로 비행한다고 보고 역산한 추정치입니다. 바람·난류 등 운용 한계는 형식(멀티콥터/리프트+크루즈/틸트)과 중량으로 추정했습니다.
- Supernal S-A2는 2025년 9월 개발이 일시 중단·재검토 중입니다(Aviation Week).
